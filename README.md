# 7K-Hiroba organization defaults

This repository contains the [Hiroba organization profile](https://github.com/7K-Hiroba), default community health files, and approved brand assets for the Inari community ecosystem.

- Governance, onboarding, and the application registry live in [7K-Hiroba/community](https://github.com/7K-Hiroba/community).
- The [Hiroba CLA status hub](https://github.com/7K-Hiroba/community/blob/main/CLA.md) links the canonical Inari CLA documents; external contributions remain paused.
- [Asset provenance](profile/assets/NOTICE.md) records the immutable 7K Group source, approved dark-green adaptations, output hashes, and rendering inputs.

Repository-local health files override these inherited organization defaults. See the [security policy](SECURITY.md) and [contribution status](CONTRIBUTING.md) before opening an issue or pull request.
